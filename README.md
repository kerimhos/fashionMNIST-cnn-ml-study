# CNN model ile pratik
Bu proje, PyTorch kullanarak bilgisayarlı görüntü modelleri geliştirmek ve bu konuda pratik yapmak için oluşturulmuştur.

## Proje Hakkında
Bu projede, PyTorch ile derin öğrenme tabanlı görüntü sınıflandırma modelleri geliştirilmiştir. Kodun büyük bir kısmı, [mrdbourke/pytorch-deep-learning](https://github.com/mrdbourke/pytorch-deep-learning/blob/main/03_pytorch_computer_vision.ipynb) repository'sindeki çalışmalardan ilham alınarak ve uyarlanarak yazılmıştır.
